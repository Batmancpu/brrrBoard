Its signed CI run is pending; no behavior is marked Reno10-verified from code alone.
- **Dictate / English-only:** The owner reports the RecognitionService route reaches Dictate but yields Hindi; the latest direction is English transcription only. brrBoard requests English but Dictate ignores caller language extras and uses its own saved Active language. brrBoard rejects final Devanagari-only results and does not render partial transcripts, but cannot reliably detect Hindi written in Latin script or change Dictate's private setting. Set Dictate → Languages → Active language = English; turn off Follow keyboard language. Do not mark English-only fixed until Reno10 confirmation.
- **Dictate issue #359:** Maintainer confirms the selected Android `SpeechRecognizer`/Dictate `RecognitionService` path keeps brrBoard visible. The voice-input IME replaces brrBoard, and `ACTION_RECOGNIZE_SPEECH` opens an activity. brrBoard uses the RecognitionService route. The issue does not provide a language-setting API for caller keyboards.
- **Themes/icons:** Automatic OG dark/light appearance with optional Apple-palette action-key tint shipped in v1.0.23; original Shift states and safe saved-icon migration shipped in v1.0.25. Visual acceptance on the owner's phone remains open.
- **Reference and known layout constraints:** The only current visual inputs are the two supplied iOS keyboard screenshots. They show three prediction slots with a highlighted center candidate, a separate compact right accessory, standard QWERTY rows, and Emoji/mic on opposite lower corners. Do not claim frame-by-frame YouTube review. The user has no visible navigation bar and wants the board lower gap reduced without crumpling footer controls; measure actual ColorOS insets and host-content bounds before changing them.
- **Existing interactions:** Source includes measured IME boundary reporting, panel/footer parity, 300 ms mic-hold input switching, 123 tap-to-Symbols/hold-to-numpad, the three-choice Emoji hold arc, and OS-owned hide animation. These remain device acceptance items.
- **brrPersonal:** The v1.0.31 source adds a finite PHINC-derived seed (CC BY 4.0, attributed in NOTICE) capped at 6,000 total entries and curated valid-only slang/profanity rules with emoji shortcuts. It reuses the existing spatial decoder; normal completion/autocorrect suppresses flagged terms, while deliberate swipe decoding retains them. The generator runs at build time; the APK gains no runtime network permission. The old unavailable 252-word worktree cannot be reconstructed exactly.
- **Smart Emoji:** Follow-up source integrates local frequency/recency ranking into the existing iOS-like Recents category, prioritizing up to three device-width rows without adding a category button or changing grid dimensions. Use counts refresh the small cache; incognito avoids adaptive ordering/writes; accepted Emoji strip selections record once. Signed CI and Reno10 appearance/quality checks are pending.
- **Learning/privacy/proofreading:** Existing UserHistoryDictionary learns locally; clear/reset UI and bounded-learning behavior still need an audit. Android's SpellCheckerService gives word-level spelling help, not Apple's Writing Tools grammar Proofread. Do not add a cloud/AI proofreader.
- **Other open work:** Reno10 checks for height/insets, text/symbol/Emoji/Clipboard/toolbar transitions, tint reset, icons/accessory, dictionary quality/latency, and Dictate English. Audit glide-library licensing/provenance and ABI compatibility before any public APK inclusion. Do not bundle the ~116 MB Apple Emoji font; Apple's glyph artwork is excluded from the source repository's MIT license. Keep the current app without INTERNET permission.
- **Hardware reference:** OPPO publishes Reno10 5G at 2412×1080/394 ppi. Runtime dp density, ColorOS build, display/font scale, keyboard-height setting, and nav insets are device-specific. iPhone 16 Plus is a size analogue, not a pixel-perfect template.
- **CI:** Obtainium run [43766685860](https://github.com/Batmancpu/brrrBoard/actions/runs/43766685860) signed and published v1.0.31. Debug run [43766685891](https://github.com/Batmancpu/brrrBoard/actions/runs/43766685891) built, verified its signer, and uploaded an APK, but the automatic test gate failed 13 of 180 existing tests (Parser currency labels, InputLogic URL/autospace, and emoji recognition).
