An optional model-bootstrap APK contains an INT8 ONNX conversion used with
sherpa-onnx. Normal APK updates do not include these weights, and instead use
the model verified and extracted into this app's private storage earlier.
Model distribution pinned for reproducible builds:
https://github.com/DevEmperor/DictateKeyboard/releases/tag/whisper-models-v1
sherpa-onnx project: https://github.com/k2-fsa/sherpa-onnx
sherpa-onnx software license: Apache License 2.0

No audio is transferred to the model's original publisher or to sherpa-onnx.
When weights are embedded, all four assets are pinned by SHA-256 and checked
during the release build. See NOTICE and tools/offline-voice-model.lock.
