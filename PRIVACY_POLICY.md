# brrBoard privacy policy

brrBoard uses local dictionaries and preferences for typing. It does not request Android internet access. Contacts, if enabled and authorized, are used for local suggestions. Clipboard history and learned suggestions can be managed in settings.

Microphone access is used only when you start dictation. brrBoard requests Android’s on-device recognizer, which requires a compatible offline model and device support. External links open in another application.

Contact the maintainer through [MangoLoads](https://batmancpu.github.io/mangoloads/).
