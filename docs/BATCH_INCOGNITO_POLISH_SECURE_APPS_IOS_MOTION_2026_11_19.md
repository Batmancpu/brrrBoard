## Privacy and security boundary

- Incognito means this keyboard does not *collect/persist* correction associations, app context, emoji usage, clipboard history or dictated audio/transcript. Audio and formatted text exist transiently in RAM for offline transcription and are disposed afterwards. The editor/application itself still receives text the user enters and may save it; brrBoard cannot erase the destination app's state or system caches.
- Model files already installed on the device are reused; do not package/download a new model. An external brrSpeak or network transcription path must never start while private.
- Secure-app preference is **not** the same as global Android private space; it is an exact `EditorInfo.packageName` match. App labels are only used for the picker.
- Proton Pass integration is a launch shortcut and does not bypass Android Autofill. No hidden inter-app credential transport or clipboard scraping.
