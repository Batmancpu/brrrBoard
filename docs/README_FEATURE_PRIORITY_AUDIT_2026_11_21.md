## Claim and evidence boundary

- **Noise reduction is real but specific:** optional Android audio-system `NoiseSuppressor` is enabled by default when available and can be switched in BR Brain. It is not a running GTCRN neural enhancement pipeline. GTCRN model files remain packaged in a safe isolated diagnostic path after a load-stage failure on the owner device. Activation does not prove accuracy improvement.
- **Voice model:** privately provisioned NVIDIA Parakeet TDT 110M INT8 with sherpa-onnx; normal model-free updates preserve previously installed weights. A fresh install needs model-inclusive bootstrap/recovery; no internet model downloader.
- **Neural BR Brain:** the bilingual ContextLM is *planned*, not trained or bundled; current intelligence uses native dictionaries, offline candidates, learned corrections and Emoji associations. No benchmark claim that it objectively outperforms Gboard or the device's default keyboard.
- **Glass:** Apple-inspired styling and Android-supported blur, not claimed byte-for-byte Apple visuals or guaranteed optical liquid-glass refraction; illustrations are not real screenshots.
- **Zero Internet:** brrBoard cannot upload keyboard data by itself because INTERNET permission is removed. A user can still export/share an unencrypted backup or open a URL in another app. These boundaries must remain obvious.
- **Privacy:** avoid depicting raw typed strings, private conversations, real user data, personal model files or actual crash diagnostic details in marketing art.
- **Release honesty:** source/CI evidence is not a substitute for independent Oppo microphone quality, active-call/earbud behavior, performance and layout acceptance.
