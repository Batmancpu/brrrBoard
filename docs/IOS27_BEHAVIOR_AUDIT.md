# iOS 27 keyboard behavior audit

Scope: the supplied iPhone references, Apple's iOS 27 iPhone guide and brrBoard source at the signed v1.0.15 baseline plus this patch. This is a source and documentation comparison. Hardware timing, typography dimensions, per-app behavior and language quality require paired testing. Keep the existing Frosted Glass renderer and the three owner-approved themes.

Apple references: [typing and QuickPath](https://support.apple.com/guide/iphone/type-with-the-onscreen-keyboard-iph3c50f96e/27/ios/27), [text editing and trackpad](https://support.apple.com/guide/iphone/select-edit-and-move-text-iph1a9cae52c/27/ios/27), [predictions](https://support.apple.com/guide/iphone/use-predictive-text-iphd4ea90231/27/ios/27), [dictation](https://support.apple.com/guide/iphone/dictate-text-iph2c0651d2/27/ios/27), [keyboard switching](https://support.apple.com/guide/iphone/add-or-change-keyboards-iph73b71eb/27/ios/27). For brrBoard use Settings, WhatsApp and another app offering ordinary multiline fields. The same text, locale, theme and app mode should be used across repeated runs. Record observed effects independently from what the source intends.

| Behavior | brrBoard status and follow-up |
| --- | --- |
| Tap, rapid typing, Shift, double-tap Shift, Delete and repeat | The current key/state and pointer paths implement the fundamentals. Compare press latency, correction on rapid taps, sound and haptic feel, Caps Lock on/off, alternating Shift, and repeat acceleration. Verify after swipe import. |
| Accented characters; number, punctuation and math pages | brrBoard uses locale-specific long-press popups and keyboard layouts with existing symbols access. Check every English and Hindi/Hinglish popup, shifted punctuation, currency and landscape. Hold 123 opens the optional large keypad, which is an owner customization. Validate footer and alignment with normal typing. |
| Space; sentence punctuation | Enable the existing double-space period by default. Keep explicit user preference and skip non-auto-space or protected fields. Test deletion/undo, URL, email, password, Search, and composing text. |
| Cursor positioning and selection | Add hold Space to activate the existing trackpad when the vertical Space gesture is configured for touchpad. This takes priority over the Space hold picker in that configuration. Tap Space still inserts a space, release/cancel exits trackpad. Test diagonal movement and release. iOS two-finger selection and hidden key labels are additional gaps. |
| QuickPath | Supports the existing local gesture decoder after one-time import. Directly accept the verified user-supplied ARM64 ZIP in both import entry points. No root or module installer runs. Gestures are already enabled by default when a library loads, unless the user disabled them. Check word recognition, candidate selection, automatic spaces, delete/retry, trail, settings retention and English/Hinglish behavior in airplane mode. Exact QuickPath ranking, supported languages and delete semantics remain to compare. |
| Suggestions, autocorrect, reversal | Local suggestions and backspace reversion exist. The earlier field recording showed candidates of mixed relevance. iOS shows inline completions and marks corrected text for touch reversal. Do not claim those interactions or ranking parity. Test sample phrases per language, correction confidence, learning and fallback, especially in Search. Next implement confidence and context rules and assess inline completion APIs separately. |
| Text replacement and dictionaries | Existing dictionary and learning machinery. Compare shortcut expansion, pasted text, mixed-script suggestions, add/remove words and incognito behavior. Apple system-wide expansion and brrBoard local dictionary shortcuts have different integration boundaries. |
| Search, Return, Go, Send, Next, URL, email, password and numeric fields | Android EditorInfo drives contextual actions. Verify icons and actual field actions, email @, URL slash, disabled learning/clipboard on sensitive fields and entry/mode changes across apps. Do not force a key Apple shows if the Android target does not advertise that action. |
| Emoji, input methods, one-handed layout and accessibility | Keep owner choices: Emoji tap, hold for Clipboard/Settings, microphone hold to switch IME, independent accessibility actions. Verify one-handed size and alignment with gesture navigation, TalkBack and display scaling. Compare Emoji search, recents, variants and panel height. |
| Copy, paste and local clipboard | Existing text and MIME-compatible image/file chips, no network path. Check fresh, stale, dismissed and sensitive items; verify supported and unsupported receiving apps. Apple Continuity/Universal Clipboard is outside brrBoard's offline scope. |
| Dictation | Android on-device provider only, themed controls, final text into current editor. Verify English and Romanized Hinglish models, start/stop/cancel, focus changes, no accidental keyboard switching, no duplicate insertions, and airplane-mode output. iOS dictation editing, punctuation and listening behavior require dedicated checks; a working provider is not guaranteed by source alone. |
| Toolbar, surface and dismissal | Keep the neutral glass and owner gestures. Validate compact empty state, centered predictions, submenu hit targets, slow and fast dismiss, no leftover blur, and stable typing/Emoji/Clipboard/numpad outer bounds. Exact response, cursor landing and animation are device checks. |

## Imported binary

The supplied Magisk archive contains its installer metadata and one ARM64 shared object. Its SHA-256 is `b1049983e6ac5cfc6d1c66e38959751044fad213dff0637a6cf1d2a2703e754f`, equal to the existing ARM64 allowlisted hash in JniUtils. Host inspection confirms ELF64/AArch64 and 64 KiB LOAD alignment. These checks establish identity and format. They do not establish runtime compatibility, output quality, or redistribution rights. The user-supplied package has no redistribution license and [upstream HeliBoard](https://github.com/HeliBorg/HeliBoard) describes the compatible engine as closed source. Keep the binary and archive out of the public repo and APK. The app imports only the expected ZIP member with size and checksum checks; the ordinary .so import and its checksum warning remain available.
