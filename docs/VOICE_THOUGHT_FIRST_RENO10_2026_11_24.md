## Hardware and decision
OPPO Reno10 5G (India) has 8 GB RAM and MediaTek Dimensity 7050: https://www.oppo.com/in/smartphones/series-reno/reno10/specs/ . The phone's physical runtime, available RAM while other apps run and thermal constraints are unknown. Existing native Parakeet offline segmenter accepts <=15s as one window; isolated legacy brrClean bridge permits 12s PCM, 384000 bytes, below Binder limits. 12s is a conservative candidate, not a measured optimum; do not increase to 20–30s before a real-device benchmark. Raw+protected PCM and flags are bounded; 12s input PCM only 384000 bytes, but native model activation/arena memory is much larger than PCM. Keep 170s session cap and installed Ultra or 110M pack. Existing model asset sizes unchanged.

Smart Turn upstream analyzes the latest 8 seconds after VAD detects a pause: https://github.com/pipecat-ai/smart-turn and https://github.com/pipecat-ai/pipecat/blob/main/src/pipecat/audio/turn/smart_turn/local_smart_turn_v3.py . This does not constrain ASR duration. 600ms quiet prompts prediction; 400ms rechecks for incomplete thought, with bounded 2.2s silence timeout, 1.2s minimum semantic batch, 12s cap. Six-second legacy pause policy remains when adaptive is disabled or unavailable. At a safety cut, choose lowest-energy/neural-safe boundary near ceiling (10–12s normal, last second in reduced modes) and retain exactly 320ms raw/protected overlap. No early forced cut at six seconds in normal mode. Per-session budget monotonically downshifts to 8s if >=2 queued chunks or previous decode real-time ratio >=0.90; 6s when Android reports low memory/available memory <=2x system threshold or thought model missing/disabled. Latch at batch boundary, never truncate queued audio; no guarantee shorter chunks improve total throughput (measure). Do not restart the recorder or treat batch/semantic completion as microphone Stop. Exact PCM accounting and alignment verified by tests.

## Implementation
- PrivateVoiceChunker bounded storage 12s; legacy default 6s for independent clients; production passes session budget. Copy at most one analysis window to guarantee correct pressure changes for arbitrarily large input frames.
- Preserve stateful isolated GTCRN, dual Silero score histories, safe outer digital-zero compaction, raw audio recovery, immediate capture and ordered RAM queue. No additional native model, no network permissions or inference on AudioRecord/UI. AlignedVoiceBuffer uses chunker maximum plus one 640ms block; Smart Turn copies only recent 8s, converts directly into fixed left-padded model window (no whole long float copy).
- OfflineVoiceEngine retains original request PCM through native inference and retries recoverable exceptions once in <=6s windows on the same worker/recognizer. Does not attempt to catch process-level native crashes; never claim crash-proof. Native errors or cancellation after which recovery fails cannot guarantee the missing speech. Keep one raw recovery attempt in the pipeline. For failed chunks after bounded recovery, retain successful chunks and continue capture; mark gap so no word deduplication across it, suppress auto-send and show partial warning on Stop. A wholly failed take errors normally. Explicit cancel, editor loss, incognito and no-deferred-insert safeguards remain unchanged.
- No new diagnostics containing audio/text. Existing elapsed-time counters remain RAM-only. Real-time ratio measured on decode callback only, not queue delay. Settings toggle describes thought-first/legacy switch.
