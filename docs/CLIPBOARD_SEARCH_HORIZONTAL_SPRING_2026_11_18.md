Two owner photos were inspected but **not added to this public repository**, because the images expose personal notes and clipboard URLs. In the first photo, Clipboard Search shows rectangular white-backed Back/Clear keys; copied text cards extend vertically into the alphabet QWERTY row. The second photo points to the persistent empty compact-Emoji band above fixed category icons. ## Source-level causes (verified by reading current source)

1. `ClipboardHistoryView.openSearch()` previously left `clipboard_list` as a **match-parent, vertical StaggeredGridLayoutManager** beneath the alphabet Search keyboard. `updateSearchPadding()` merely increased RecyclerView's bottom padding: it did not shrink the sharp drawing viewport. Simultaneously `clipboard_bottom_glass` became `GONE`, so `ClipboardGlassFrameLayout.drawChild` deliberately skipped its only bottom clipping rule. Tall URL cards remained visible behind key rows. This accounts for the photographed overlap without blaming keyboard artwork or the host blur.
2. `ClipboardHistoryRecyclerView` installs a horizontal `ItemTouchHelper` swipe-to-delete, so simply turning the same list horizontal would pit scroll against destructive swipe. Search now disables that gesture **only** in horizontal mode; standard Clipboard Browse retains it.
3. `clipboard_search_back` and `clipboard_search_clear` were ImageButtons without a code-set Emoji-equivalent round ripple, leaving theme-default square backgrounds. Search text's foreground/hint colors also did not use the `TOOL_BAR_KEY` role. The corrected controls use the same round special-key role and toolbar text tint as Emoji Search; Clear is hidden until a query exists.
4. The shared ABC footer dispatches `KeyCode.ALPHA`. Inside Clipboard/Emoji Search the *same* alphabet view is reparented to the panel; `KeyboardSwitcher.setMainKeyboardFrame()` intentionally preserves a currently active Search panel. Thus ABC changes its internal alphabet state but **does not exit the panel**. The footer now requests a controlled Search/Expanded collapse and then dispatches the same existing key code; it does not replace keyboard listeners or type the query into the host.
5. `KeyboardSwitcher.transitionToPanel()` formerly hid the outgoing panel synchronously, then faded the sole visible main keyboard from alpha 0. This can expose the host backdrop as a glowing flash during return-to-ABC. Direct panel→typing return now presents the alphabet at full opacity **after** the bounded spring shrink, without touching host-app/system swipe-down dismissal animation.

## Focused implementation candidate

- Clipboard Search has one `RecyclerView.HORIZONTAL` row, positioned 48dp below its field with a 96dp viewport, bounded 80dp cards (max three visible text lines; **full clip text stays intact for paste**), max-width 220dp; the normal vertical masonry/pin/delete layout returns on Close. Its scroll state is saved and restored; no clipboard contents are copied to new stores.
- `ClipboardGlassFrameLayout` clips `clipboard_list` to the visible Search keyboard's top on all Android versions, even when the bottom glass is absent; normal live glass drawing still follows the approved Android-12+ hardware path. `ClipboardHistoryRecyclerView` disables left/right swipe-to-delete in Search so horizontal browsing cannot erase an item by mistake.
- Clipboard Search uses the same height-growth policy as Expanded Emoji (+160dp over a reconciled native typing viewport, capped by the actual IME window), with the existing bounded critically damped spring interpolator. Both panels now use 260ms rather than 320ms for a faster grow/shrink; mode changes honor Android's disabled-animations setting. Emoji limits offscreen pager pages to one adjacent during height animation to avoid five full RecyclerViews remeasuring every frame, while retaining per-page row caching.
- Footer ABC requests a Search/Expanded collapse first and sends normal `ALPHA` after it finishes; the compact-panel ABC path remains immediate. `KeyboardSwitcher` skips its old alpha-zero flash when returning from Emoji/Clipboard to typing. Shared footer drawing, live source blur, global IME backdrop, package/signature and input/privacy contract are **not** altered.
