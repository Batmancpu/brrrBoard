# Scale Improved and responsive Settings search — 26 November 2026

## Owner request and diagnosis
Owner preferred the original Scale preset (subjective ~90% of desired iOS feel), explicitly cautioned that faster emergence was not necessarily the cure, requested only Scale and Scale Improved plus Settings search/overall Settings lag repair. Preserve the existing Scale visual parameters. Source audit: QuickTypeMotion uses one smoothstep for all properties, drops low-opacity active glyphs and reconstructs order by x; repeated provisional/final updates can restart easing. SettingsContainer recomputed localized title/description/category normalization, tokenization and route mapping for each query, synchronously from the Compose lazy-list builder; SearchScreen had a full-size Haze/offscreen layer even during IME input. These are concrete avoidable costs, not a device profiling result.

## Implementation and safeguards
- Only `scale` and `scale_improved` remain; legacy classic/ripple/spring or invalid IDs resolve to Scale without rewriting existing preferences. Existing Scale 145ms related/130ms replacement, 12% entry scale, compression, smoothstep and no stagger remain intact. Global motion, reduced motion and battery policy unchanged.
- Improved keeps the same overall envelope and growth curve, independent mild opacity curves, 2ms per unmatched glyph stagger capped at 10ms within the original duration. Finite cubic Hermite positions preserve bounded incoming x/y momentum, finish exactly with zero velocity, limit reverse impulse; no overshoot gimmick or mandatory delay. Prefix/suffix anchors and active logical glyph indices avoid matching outgoing faded ink; same-target retargets retain remaining duration rather than restart a complete animation. Native Paint run advances and Canvas drawTextRun preserve more shaping/kerning; API29+ batched advances and cursor checks, older API24+ run-advance fallback, native fallback for nonseparable clusters, ellipsis and unsupported text. No new per-frame list allocation, decoder invocation, layouts or unbounded tracks; existing frame-budget snap retained. Tap targets, actual suggestions, confidence pill geometry and its 33ms chrome timing remain native and unchanged. Native exact visual parity still requires device verification.
- Playground two choices, regular/rapid sample replay and apostrophe/repeated-letter examples, real renderer and live keyboard tryout. No private text.
- Settings search immutable lazily built index, precompiled normalization/token regex, original route/alias/relevance ordering and 40-result cap preserved. Public built-in filtering runs on Dispatchers.Default with cancellation and current-query guard. Keep previous visible results while a new public query is pending; do not show a false empty result before completion. Stable setting keys/content type. Generic/custom UI-dependent filters remain synchronous. No normal filtering receives armed secret input; deadline, authentication, FLAG_SECURE and lifecycle logic untouched. Composition local uses tracked reads rather than static invalidation.
- Haze/offscreen source and header child are omitted while the IME or active search is present, replaced by existing opaque surface color; restore ordinary idle Haze and retain explicit active-overlay backdrop behavior. This is Settings-only, never disables keyboard frosted glass. No new permission, telemetry, dictionary, ContextLM, prediction scoring, voice or layout changes.
