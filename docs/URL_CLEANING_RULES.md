# Local clean-link policy — reviewed subset (2026-11-25)

Reference reviewed: https://github.com/kisst/link-clear/blob/c0a685a876e2fc2e6f8d230a84241143352ce130/core/src/main/resources/clearurls/data.min.json (ClearURLs rule data, LGPL-3.0; upstream https://github.com/ClearURLs/Rules). This implementation uses independently written Java and selected tracking-parameter names/host exceptions; it does not vendor the full dataset or third-party engine. No regex rule execution, redirect unwrapping, DNS, network, runtime update or extra permission. Do not represent the subset as complete ClearURLs compatibility.

Select literal high-confidence campaign/click IDs, scope ambiguous names to known hosts, retain unknown parameters byte-for-byte, and preserve conservative exceptions for application navigation and payment/download/API endpoints. Existing authentication, signed URL, userinfo, malformed URL, internal host and fragment checks remain prior to any transformation. Never rewrite clipboard; only explicit Chrome action can invoke the cleaner. If a URL is rejected it is not opened by this action. Test raw query encoding, repeated keys, anchors, idempotence, sensitive URLs, domain spoofing and exceptions before extending.
