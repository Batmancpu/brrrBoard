## Safeguards and non-destructive defaults

1. Configured Secure Apps remain incognito by default. A manual OFF request in one must emit a restrained warning haptic (if haptics/DND allow). Show a wide, spacebar-exact slide-to-confirm control, with alphabet glyphs faded away like trackpad mode; no automatic preference flip, learning, analytics or content logging. An incomplete, wrong-direction, cancelled or interrupted gesture changes nothing. A completed deliberate slide may opt out only in the **current editor session**, never persist a per-app exception; starting/finishing an editor, hiding the IME, a protected/password/no-learning input and global always-incognito settings must deny or reset it. Recheck editor generation and current package before committing. Accessiblity offers explicit confirmation equivalent, never bypasses protected-field policy.
2. Put a visible **Clear recent clipboard** action at the end of the scrollable Clipboard list. Require the same spacebar-sized slide after tap; search/other panels and editor transitions cancel. Reuse `ClipboardHistoryManager.clearHistory()`: clears unpinned brrBoard history and only a still-verifiably-brrBoard-owned current system clip, never another app's clipboard, protected content or pinned items. Wording must not imply pinned clips are erased. No private contents in UI/logs.
3. Guard genuinely irreversible settings operations with a reusable Compose slide control, prioritizing Clear learned typing history and Erase swipe learning (including duplicate entry points). Restore-from-backup may overwrite local data and merits deliberate confirmation before opening a picker. Backup deletion has **no present in-app action**—archives live in Android Downloads/SAF, so do not invent broad storage deletion privileges. Preserve usual quick, safe Settings toggles and undoable single-item actions.
4. Clipboard Browse's bottom keyboard row + shared ABC/mic footer must appear as **one** moving internal blurred slab, without a divider. Reuse the existing in-IME RenderNode source and overflow the single bottom glass beneath the shared footer; suppress the redundant footer-local glass for Clipboard only. Maintain sharp card clipping above controls and keep Emoji Search/Clipboard Search and accessibility separate. No host-app screenshot/bitmap layer.

## Proposed regression matrix

- Swipe policy: threshold, drag direction, finger capture, cancellation on second pointer, release outside/end, low motion, keyboard hiding. Unfinished slides must never invoke callbacks.
- Secure Apps: configured app first entry, OFF request haptic, preview, completed deliberate slide, no learning before completion, same-editor temporary opt-out, next field/app/restart restoration, forced password/no-learning/global always-private refusal, old async suggestion generation ignored, normal nonsecure incognito unchanged, TalkBack.
- Clipboard: clear-at-end visible only if entries exist and not searching, pinned retained, unpinned removed only after full slide, owned system clip cleared only if still matching, foreign clip untouched, search transitions, scroll and footer alignment.
- Settings: no one-tap erase, cancel/dismiss, full deliberate slide, persistent data preserved until completion, backups restored only after an explicit slide and chosen SAF document, no arbitrary backup deletion.
- Visual/Oppo: exact physical spacebar bounds, background glyph fade rather than instant flash, knob spring/reverse and gentle haptics, dark/light/frosted themes, portrait/landscape/one-handed, quick Emoji/Clipboard/ABC switches, live blur without seam.
